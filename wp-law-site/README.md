# سایت وکالت «دادور» — قالب وردپرس فارسی + افزونهٔ همراه

یک قالب سبک و اختصاصی وردپرس (راست‌به‌چپ، موبایل‌محور، سازگار با المنتور) برای وکیل یا دفتر وکالت، به‌همراه افزونه‌ای که داده‌های ماندگار (خدمات، اطلاعات دفتر، فرم درخواست مشاوره) را نگه می‌دارد.

> این پوشه مستقل از برنامهٔ حسابداری «با شرف» در همین مخزن است و هیچ وابستگی‌ای به آن ندارد.

## بسته‌های نصب (`dist/`)
| فایل | چیست | نصب از |
|---|---|---|
| `dadvar-1.0.0.zip` | قالب | نمایش ← پوسته‌ها ← بارگذاری |
| `dadvar-core-1.0.0.zip` | افزونهٔ همراه (لازم) | افزونه‌ها ← بارگذاری |
| `dadvar-child-1.0.0.zip` | قالب فرزند (فقط برای شخصی‌سازی کدی) | نمایش ← پوسته‌ها ← بارگذاری |
| `SHA256SUMS.txt` | اثرانگشت فایل‌ها | — |
| `../elementor-templates/*.json` | قالب صفحات برای ورود در المنتور | قالب‌ها ← ورود قالب‌ها |

**ترتیب نصب:** المنتور ← قالب ← افزونهٔ همراه ← «اطلاعات دفتر» ← (اختیاری) «محتوای نمونه». جزئیات: [docs/guide-fa.md](docs/guide-fa.md).

```
cd wp-law-site
scripts/build.sh
```

## ⚠️ محدودیت مهم این نسخه
المنتور در محیط ساخت قابل‌اجرا نبود؛ همهٔ آزمون‌ها در حالت «بدون المنتور» انجام شده‌اند. ویرایش صفحات در المنتور باید پیش از انتشار روی Staging آزمون شود (PROJECT_STATUS.md).
