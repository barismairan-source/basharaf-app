# گزارش آزمون — نسخهٔ 1.0.0 (2026-10-06)

## محیط آزمون
- Ubuntu 24.04، PHP 8.3.6، MariaDB 10.11.14، سرور داخلی PHP (`php -S`، بدون gzip/HTTP2/کش)، وردپرس 7.1.2 (از مخزن رسمی گیت‌هاب)، زبان سایت fa_IR.
- Chromium (Playwright 1.56.1)، axe-core 4.14.0، Lighthouse 12.8.2.
- **المنتور در این آزمون‌ها نصب نبود** (پایین را ببینید). همهٔ نتیجه‌ها برای حالت «بدون المنتور» است که صفحه‌های نمونه با HTML ساده ساخته شده‌اند.
- بستهٔ زبان فارسی وردپرس از wordpress.org قابل دریافت نبود؛ برای آزمون راست‌به‌چپ یک فایل ترجمهٔ حداقلی (فقط جهت متن) ساخته شد. قالب در نبود بستهٔ زبان هم جهت را برای زبان فارسی راست‌به‌چپ می‌کند.
- ایمیل: به‌جای سرور ایمیل واقعی، `sendmail_path` به اسکریپتی وصل شد که پیام را در فایل ذخیره می‌کند.

## اجرای دوبارهٔ آزمون‌ها
```
tests/integration.sh /path/to/wordpress https://staging.example.com
SITE_URL=https://staging.example.com node tests/browser/interact.js   # نیازمند playwright و axe-core
SITE_URL=https://staging.example.com node tests/browser/shots.js docs/screenshots
phpcs   # با phpcs.xml.dist
```
آزمون‌ها درخواست آزمایشی ثبت می‌کنند؛ فقط روی محیط آزمایشی اجرا شوند.
