# راهنمای نصب و مدیریت سایت وکالت (فارسی)

این راهنما برای مدیر سایت نوشته شده و نیاز به برنامه‌نویسی ندارد. اصطلاحات فنی هرجا لازم بوده توضیح داده شده‌اند.

---

## ۱. پیش‌نیازها

| مورد | حداقل | پیشنهاد |
|---|---|---|
| وردپرس | ۶٫۷ | آخرین نسخهٔ پایدار (آزمایش‌شده با ۷٫۱٫۲) |
| PHP | ۷٫۴ | ۸٫۲ یا بالاتر (آزمایش‌شده با ۸٫۳) |
| پایگاه داده | MySQL 5.5.5 یا MariaDB | MariaDB 10.6+ / MySQL 8 |
| زبان وردپرس | — | فارسی (تنظیمات ← عمومی ← زبان سایت) |
| HTTPS | الزامی برای سایت عمومی | گواهی رایگان Let's Encrypt از پنل هاست |
| ارسال ایمیل | — | افزونهٔ SMTP (بخش ۷) |

## ۲. ترتیب نصب (مهم)

ابتدا یک **نسخهٔ آزمایشی** (Staging) روی زیردامنه یا هاست جدا بسازید و همه‌چیز را آن‌جا امتحان کنید.

1. وردپرس را نصب و زبان را فارسی کنید. در «تنظیمات ← خواندن» گزینهٔ **«از موتورهای جست‌وجو بخواهید…» را روی نسخهٔ آزمایشی تیک بزنید** (روی سایت اصلی هنگام انتشار برش دارید).
2. **المنتور** (رایگان) را از «افزونه‌ها ← افزودن» نصب و فعال کنید.
3. **قالب:** نمایش ← پوسته‌ها ← افزودن ← بارگذاری پوسته ← `dadvar-1.0.0.zip` ← نصب ← فعال‌سازی.
   (اختیاری) اگر قرار است کسی کد شخصی بنویسد، `dadvar-child-1.0.0.zip` را هم نصب و **همان را** فعال کنید.
4. **افزونهٔ همراه:** افزونه‌ها ← افزودن ← بارگذاری افزونه ← `dadvar-core-1.0.0.zip` ← نصب ← فعال‌سازی.
5. **اطلاعات دفتر:** منوی «دفتر وکالت ← اطلاعات دفتر» را کامل کنید (فقط اطلاعات واقعی).
6. (اختیاری) **محتوای نمونه:** «دفتر وکالت ← محتوای نمونه ← ورود محتوای نمونه». صفحه‌ها، چهار خدمت، سه مقاله، منوها و رنگ/فونت المنتور ساخته می‌شوند. چندبار زدنش موارد تکراری نمی‌سازد و چیزی را بازنویسی نمی‌کند.
7. «تنظیمات ← پیوندهای یکتا» را باز کنید و یک‌بار «ذخیره» بزنید (برای اطمینان از نشانی‌های `/services/...`).
8. (اختیاری) **قالب‌های JSON المنتور:** اگر محتوای نمونه را وارد نکردید، می‌توانید فایل‌های پوشهٔ `elementor-templates/` را از «قالب‌ها ← قالب‌های ذخیره‌شده ← ورود قالب‌ها» وارد کنید و در هر برگه از کتابخانهٔ المنتور درج کنید. پیوندهای داخل این قالب‌ها نسبی‌اند (`/contact/`، `/about/`).

> اگر محتوای نمونه را **پیش از** فعال‌کردن المنتور وارد کنید، صفحه‌ها به‌صورت HTML ساده ساخته می‌شوند و در المنتور قابل‌ویرایش نیستند. در این حالت «حذف محتوای نمونهٔ ویرایش‌نشده» را بزنید، المنتور را فعال کنید و دوباره وارد کنید.

> وردپرس هنگام فعال‌شدن قالب گاهی ابزارک‌های پیش‌فرض (بایگانی، دسته‌ها و…) را در «پابرگ — ستون آزاد» می‌گذارد. اگر نمی‌خواهید، از «نمایش ← ابزارک‌ها» حذفشان کنید.

## ۳. چه چیزی کجا ویرایش می‌شود

| می‌خواهم… | مسیر در پیشخوان |
|---|---|
| شماره تلفن، ایمیل، نشانی، ساعات کاری، پیوند مسیریابی، شبکه‌های اجتماعی | **دفتر وکالت ← اطلاعات دفتر** (همه‌جای سایت از همین‌جا می‌خواند) |
| نام وکیل، عنوان، شمارهٔ پروانه، مرجع صدور، حوزهٔ فعالیت | دفتر وکالت ← اطلاعات دفتر |
| لوگو و نشان مرورگر (favicon) | نمایش ← سفارشی‌سازی ← هویت سایت |
| منوی بالا و پایین | نمایش ← فهرست‌ها (جایگاه «منوی اصلی» و «منوی پابرگ») |
| متن و مقصد دکمهٔ «درخواست مشاوره» سربرگ، نمایش دکمهٔ تماس، متن پابرگ، حق نشر | نمایش ← سفارشی‌سازی ← سربرگ و پابرگ |
| رنگ‌ها و فونت سراسری | المنتور ← تنظیمات سایت ← رنگ‌های سراسری / فونت‌های سراسری |
| متن، تصویر، دکمه و ترتیب بخش‌های خانه/درباره/تماس | روی برگه «ویرایش با المنتور» |
| افزودن/ویرایش خدمت | پیشخوان ← خدمات (عنوان، «چکیده» برای کارت، «ترتیب» برای جایگاه در فهرست؛ بدنه با المنتور) |
| مقاله | نوشته‌ها ← افزودن (ویرایشگر وردپرس). نویسنده = کاربر واقعی؛ «زندگی‌نامه» کاربر زیر مقاله نمایش داده می‌شود |
| دیدن درخواست‌های مشاوره | دفتر وکالت ← درخواست‌ها |
| مدت نگهداری درخواست‌ها و ایمیل دریافت اعلان | دفتر وکالت ← اطلاعات دفتر ← فرم درخواست مشاوره |
| اعضای دفتر (فقط دفتر چندنفره) | اطلاعات دفتر ← «دفتر چندعضوی است» را روشن کنید؛ منوی «اعضا» ظاهر می‌شود |

### کار با المنتور
- **تغییر متن:** روی متن کلیک کنید و بنویسید.
- **تغییر تصویر:** روی ابزارک تصویر کلیک ← «انتخاب تصویر». «متن جایگزین» (alt) را در کتابخانهٔ رسانه بنویسید. عکس‌ها را پیش از بارگذاری به عرض حداکثر ۱۶۰۰px و حجم زیر ۳۰۰ KB برسانید.
- **جابه‌جایی بخش‌ها:** از «ناوبر» (Navigator، کلید Ctrl+I) بخش را بکشید و جابه‌جا کنید.
- **ابزارک‌های اختصاصی** در گروه «سایت وکالت»: اطلاعات تماس دفتر، دکمهٔ تماس تلفنی، فرم درخواست مشاوره، فهرست خدمات، مقالات منتخب، مشخصات حرفه‌ای وکیل. دادهٔ این‌ها از «اطلاعات دفتر»، «خدمات» و «نوشته‌ها» می‌آید؛ در خود ابزارک فقط نمایش (تعداد، ستون‌ها، متن دکمه) تنظیم می‌شود.
- برگه‌های ساخته‌شده با المنتور عنوان قالب را نشان نمی‌دهند؛ عنوان اصلی صفحه (H1) را با ابزارک «عنوان» در بالای صفحه نگه دارید.

### المنتور رایگان یا Pro؟
همهٔ صفحات با **نسخهٔ رایگان** ساخته و ویرایش می‌شوند. سربرگ و پابرگ را قالب می‌سازد و از منوها/سفارشی‌سازی/اطلاعات دفتر ویرایش می‌شوند. اگر بخواهید سربرگ/پابرگ یا قالب مقاله را **با کشیدن و رها کردن** طراحی کنید، به **Elementor Pro** (مجوز سالانهٔ پولی؛ قیمت فعلی را از elementor.com بررسی کنید) نیاز دارید؛ قالب آمادهٔ آن است و بدون تغییر کد، قالب‌های Pro جایگزین سربرگ/پابرگ قالب می‌شوند.

## ۴. محتوای نمونه را چطور جایگزین کنم؟

همهٔ متن‌های نمونه با «[نمونه]» یا «[متن نمونه]» مشخص شده‌اند. پیش از انتشار:
- [ ] همهٔ فیلدهای «اطلاعات دفتر» واقعی شوند (تا وقتی مقدار نمونه مانده، پیام زرد در پیشخوان می‌آید و دادهٔ ساختاریافته خاموش است).
- [ ] تصویر جایگزین وکیل با عکس واقعی (با اجازهٔ انتشار) جایگزین شود.
- [ ] خدمات نمونه با خدمات واقعی جایگزین یا حذف شوند؛ پرسش‌های متداول با پاسخ‌های تأییدشدهٔ وکیل.
- [ ] مقالات نمونه حذف یا بازنویسی و توسط وکیل تأیید شوند.
- [ ] برگه‌های «حریم خصوصی» و «توضیحات حقوقی» توسط وکیل بازبینی شوند.
- [ ] **هیچ** آمار، افتخار، نظر موکل یا «پروندهٔ موفق» بدون دادهٔ واقعی و اجازهٔ کتبی منتشر نشود.
- دکمهٔ «حذف محتوای نمونهٔ ویرایش‌نشده» فقط مواردی را پاک می‌کند که بعد از ورود دست نخورده‌اند.

## ۵. فرم درخواست مشاوره

- درخواست‌ها در «دفتر وکالت ← درخواست‌ها» ذخیره می‌شوند؛ وضعیت (جدید / تماس گرفته شد / بسته شد) را همان‌جا تغییر دهید.
- ایمیل اعلان فقط نام، تلفن و موضوع را دارد؛ متن کامل در پیشخوان است (قابل تغییر در تنظیمات).
- در صفحهٔ هر درخواست، «ایمیل اطلاع‌رسانی» نشان می‌دهد ایمیل به سرور تحویل شد یا نه. **«تحویل شد» یعنی دریافت قطعی نیست**؛ بعد از راه‌اندازی، یک درخواست آزمایشی بفرستید و صندوق ایمیل (و پوشهٔ هرزنامه) را نگاه کنید.
- درخواست‌های قدیمی‌تر از «مدت نگهداری» (پیش‌فرض ۱۸۰ روز) خودکار حذف می‌شوند. برای حذف اطلاعات یک فرد: ابزارها ← پاک‌کردن اطلاعات شخصی.
- فرم فایل نمی‌پذیرد و نباید جزئیات محرمانهٔ پرونده در آن نوشته شود (راهنمای فرم همین را می‌گوید).

## ۶. افزونه‌های پیشنهادی (فقط یکی از هر نوع)

| افزونه | کاربرد | هزینه | ضرورت | اثر بر نگهداری |
|---|---|---|---|---|
| Elementor | ویرایش صفحات | رایگان | **لازم** | به‌روزرسانی منظم |
| یک افزونهٔ SMTP (مثلاً WP Mail SMTP یا FluentSMTP) | ارسال مطمئن ایمیل فرم از طریق سرویس ایمیل دامنه | رایگان | **به‌شدت توصیه** | کم؛ رمز SMTP را در تنظیمات افزونه/wp-config بگذارید، نه در کد |
| یک افزونهٔ سئو (Yoast SEO یا Rank Math، نه هر دو) | عنوان/توضیح هر صفحه، نقشهٔ سایت پیشرفته | نسخهٔ رایگان کافی است | اختیاری | متوسط؛ اگر LocalBusiness آن را فعال کردید، «دادهٔ ساختاریافته» در اطلاعات دفتر را خاموش کنید |
| افزونهٔ پشتیبان‌گیری (یا پشتیبان پنل هاست) | پشتیبان فایل و پایگاه داده | رایگان/پولی | **لازم** (اگر هاست ندارد) | کم |
| افزونهٔ کش (مثلاً کش پنل هاست یا LiteSpeed Cache روی هاست LiteSpeed) | سرعت | رایگان | اختیاری | صفحه‌های پیشخوان، المنتور و `wp-json` را کش نکنید؛ فرم با کش سازگار است |

افزونهٔ فرم‌ساز، اسلایدر، آمارگیر یا «امنیتی» همه‌کاره لازم نیست.

## ۷. پیش از انتشار عمومی (چک‌لیست)

- [ ] HTTPS فعال و «نشانی وردپرس/سایت» با `https://` در تنظیمات ← عمومی.
- [ ] تیک «از موتورهای جست‌وجو بخواهید…» **برداشته شود**.
- [ ] در `wp-config.php`: `WP_DEBUG_DISPLAY` خاموش (خطای فنی به بازدیدکننده نشان داده نشود).
- [ ] افزونهٔ SMTP تنظیم و یک فرم آزمایشی واقعی ارسال و دریافت شود.
- [ ] محتوای نمونه جایگزین شود (بخش ۴).
- [ ] نشانی‌ها: «تنظیمات ← پیوندهای یکتا» روی «نام نوشته».
- [ ] پشتیبان کامل تهیه شود (docs/update-fa.md).
- [ ] نقشهٔ سایت (`/wp-sitemap.xml` یا نقشهٔ افزونهٔ سئو) در Google Search Console ثبت شود.
- [ ] رمز عبور قوی و ورود دومرحله‌ای برای حساب مدیر.

## ۸. دستورهای WP-CLI (برای پشتیبان فنی)

```
wp dadvar demo import --user=<مدیر>      # ورود محتوای نمونه (تکرارپذیر)
wp dadvar demo remove --user=<مدیر>      # حذف نمونه‌های ویرایش‌نشده
wp dadvar export-templates <پوشه>         # خروجی JSON قالب‌های المنتور
wp dadvar migrate                         # اجرای مهاجرت داده (تکرارپذیر)
wp dadvar purge-inquiries                 # حذف فوری درخواست‌های منقضی
```

کدهای کوتاه (برای صفحه‌هایی که با المنتور ساخته نمی‌شوند):
`[dadvar_consultation_form]`، `[dadvar_office_info]`، `[dadvar_office field="phone"]`، `[dadvar_call_button]`، `[dadvar_services count="6"]`، `[dadvar_posts count="3"]`، `[dadvar_lawyer]`.
